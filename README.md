# EncodeChecker (文字コード・改行コード判定ツール)

EncodeCheckerは、指定したフォルダ配下のファイルを走査し、文字コード（Encoding）と改行コード（Newline）を自動判定するデスクトップアプリケーションです。
システム移行やソースコードの文字コード統一など、大量のファイルを一括でチェックしたい業務に最適です。

## 主な機能

- **一括判定**: 指定フォルダ内の全ファイルを再帰的にスキャンし、結果を一覧表示します。
- **高精度なエンコーディング推定**: `chardetng` ライブラリを採用し、日本語（Shift_JIS, EUC-JP等）を含む多様な文字コードを高い精度で判定します。
- **改行コードの識別**: CRLF、LF、CR を正確に判定します。
- **期待値チェック**: ユーザーが設定した「期待する文字コード・改行コード」と一致しないファイルを「NG」として即座に強調表示します。
- **柔軟な除外設定**: `.git` や `node_modules` などのフォルダ、およびバイナリファイル（`.exe`, `.pdf`, `.xlsx` 等）をスキャン対象から除外できます。
- **検索・フィルタリング**: ファイルパスによる絞り込みや、NGファイルのみの表示が可能です。
- **CSVエクスポート**: 判定結果をCSVファイルとして保存し、Excel等で二次利用できます。
- **超コンパクト設計**: 判定結果のテーブル表示領域を最大化するため、UIを極限までコンパクトに設計しています。

## 使い方

1. **フォルダ選択**: 画面上部の「参照」ボタンから、チェックしたいプロジェクトのフォルダを選択します。
2. **期待値設定**: 文字コード（デフォルト: UTF-8）と改行コード（デフォルト: LF）の期待値を選択します。
3. **実行**: 「実行」ボタンをクリックするとスキャンが開始されます。
4. **結果確認**:
   - ステータスが「NG」のファイルは赤色で表示されます。
   - 右上の「NGのみ」にチェックを入れると、不一致ファイルだけを確認できます。
5. **CSV出力**: 必要に応じて「CSV出力」ボタンから結果を保存します。
6. **除外設定**: 歯車アイコンをクリックすると、スキャンから除外したいフォルダや拡張子をカスタマイズできます。

## 技術構成

- **フロントエンド**: Svelte 5 (Runes), TypeScript, Tailwind CSS, shadcn-svelte
- **バックエンド**: Tauri v2, Rust
- **主要ライブラリ**: `walkdir`, `chardetng`, `encoding_rs`, `lucide-svelte`

## 開発環境のセットアップ

### 必須ツール
- [Node.js](https://nodejs.org/) (v20以上推奨)
- [Rust](https://www.rust-lang.org/) (stable)

### 依存関係のインストール
```bash
npm install
```

### 開発用サーバーの起動
```bash
npm run tauri dev
```

### パッケージのビルド（インストーラー作成）
```bash
npm run tauri build
```
