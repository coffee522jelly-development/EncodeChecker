# EncodeChecker (文字コード・改行コード判定ツール)

EncodeCheckerは、指定したフォルダ配下のファイルを走査し、文字コード（Encoding）と改行コード（Newline）を自動判定する超軽量デスクトップアプリケーションです。
ツールバー形式の極めてコンパクトなUIを採用しており、大量の検査結果を一画面で効率的に確認できます。

## 主な機能

- **超コンパクトなツールバーUI**: 画面占有を最小限に抑え、データ表示領域を最大化。
- **一括判定**: 指定フォルダ内の全ファイルを再帰的にスキャンし、結果を一覧表示します。
- **高精度なエンコーディング推定**: `chardetng` ライブラリを採用し、日本語（Shift_JIS, EUC-JP等）を含む多様な文字コードを高い精度で判定します。
- **改行コードの識別**: CRLF、LF、CR を正確に判定します。
- **ステータス表示**: OK / NG / BINARY / UNKNOWN をカラーバーで直感的に識別。
- **柔軟な除外設定**: 歯車アイコンから、スキャン対象外とするフォルダや拡張子をカスタマイズ可能。
- **CSVエクスポート**: 判定結果を即座にCSV出力。

## 使い方

1. **フォルダ選択**: 左上のフォルダアイコンから、チェックしたいフォルダを選択します。
2. **期待値設定**: 文字コード（ENC）と改行コード（NL）の期待値を選択します。
3. **実行**: 右上の「実行」ボタンをクリックします。
4. **結果確認**:
   - 左端に赤いバーが表示されるファイルは「NG」です。
   - フィルター機能や「NGのみ」チェックボックスで結果を絞り込めます。
5. **設定**: 歯車アイコンから除外ルールを設定できます。

## 技術構成

- **フロントエンド**: Svelte 5 (Runes), TypeScript, Tailwind CSS, Lucide Icons
- **バックエンド**: Tauri v2, Rust
- **主要ライブラリ**: `walkdir`, `chardetng`, `encoding_rs`

## 開発環境のセットアップ

### 必須ツール
- [Node.js](https://nodejs.org/) (v20以上推奨)
- [Rust](https://www.rust-lang.org/) (stable)

### 依存関係のインストール
```bash
npm install
```

### 開発用サーバーの起動
```bash
npm run tauri dev
```

### パッケージのビルド（インストーラー作成）
```bash
npm run tauri build
```
